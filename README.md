# DOCS-runbooks-playbooks

Practical, open runbooks and playbooks for security operations.

The goal of this repository is to share hands-on, step-by-step material that SOC analysts, incident responders and threat hunters can read, adapt and reuse, starting with email security (phishing/spam handling) and threat hunting with KQL in Microsoft Defender XDR.

---
> [!WARNING]
> 🚧 **Work in progress.** Documents are being drafted and reviewed, and content may change, some are still only in Portuguese.

## Why this repo exists

Good operational knowledge is often scattered across wikis, chats and people's heads. This repository aims to:

- **Standardize** how common security cases are handled, so results are consistent.
- **Speed up onboarding** for new analysts with clear, visual, actionable guides.
- **Share reusable content** (queries, checklists, decision steps) with the wider community.
- **Keep it simple**: short documents, real workflows, no unnecessary theory.

## How to use

1. Browse the folders above and open the document that matches your case.
2. Adapt names, domains, thresholds and tooling to your own environment.
3. Test queries and procedures in a safe context before using them in production.


## Contributing

Suggestions and improvements are welcome.

2. Fork the repository and create a branch.
3. Submit a pull request with a short description of what changed and why.

Please keep contributions vendor-neutral where possible, and **never include real company data** (domains, email addresses, hostnames, IDs, screenshots with internal information).

## Disclaimer

The content is provided for educational and operational guidance. Queries and procedures are examples and must be reviewed, tested and tuned before use in production. All names, domains and addresses shown are placeholders. Use at your own risk.
